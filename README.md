# iRMqrScanner v1.3 🖥️🔍
Sistema de gestión de relaciones internas con escaneo de códigos QR.

## Descripción 📄
Aplicación web para registrar y gestionar accesos de empleados mediante códigos QR. Incluye:
- Login con roles (Administrador, Mesa-Control, etc.)
- Escaneo de QR en tiempo real
- Registro de movimientos
- Panel administrativo (usuarios, empleados, sucursales)

## Características 🚀
- Escaneo de QR con cámara web
- Registro de motivos de visita
- Reportes filtrados por fechas
- Gestión de usuarios y permisos

## Requisitos 📋
- Servidor web (Apache/Nginx)
- PHP 7.4+
- MySQL 5.7+
- Navegador moderno con acceso a cámara
